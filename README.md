# Веб-програмування: практичні завдання

Розв’язки дев’яти практичних завдань до екзамену з дисципліни «Веб-програмування».
Кожне завдання — окремий клієнт-серверний додаток. Серверна частина написана на Node.js
лише з вбудованими модулями (`http`, `fs`, `path`): сервер віддає сторінку, а потрібну
поведінку реалізує клієнтська частина.

| № | Клієнтська частина | Що робить сторінка | Каталог | Порт |

| 2 | Тільки JavaScript | Таблиця викладачів; «Старт» обчислює середній вік | [task-2-average-age-js](task-2-average-age-js) | 3002 |

## Вимоги

Node.js 20.19+ або 22.12+.

## Запуск

Завдання 1, 2, 4, 5, 7, 8 не мають залежностей:

```bash
cd task-1-average-age-html
npm start
```

Завдання 3, 6, 9 (React) перед запуском потрібно зібрати:

```bash
cd task-3-average-age-react
npm install
npm run build
npm start
```

Сторінка відкривається за адресою `http://localhost:<порт>`. Порт указано в таблиці,
його можна змінити змінною оточення `PORT`.

## Як влаштовані завдання

- **HTML, CSS, JavaScript** (1, 4, 7): розмітка, стилі та скрипт лежать у `public/`, `server.js` віддає ці файли.
- **Тільки JavaScript** (2, 5, 8): усі елементи сторінки та їхні стилі створює `public/app.js` через DOM API.
  Сервер віддає лише мінімальний HTML-документ, який підключає цей скрипт.
- **React** (3, 6, 9): компоненти лежать у `src/`, збирає їх Vite. `server.js` віддає зібраний застосунок із `dist/`.
